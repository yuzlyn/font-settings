# Built-in Emoji fonts

The release archive contains four Android-compatible SFNT color fonts. All four
files expose `CBDT` and `CBLC` tables.

| Preset | Module path | Source |
| --- | --- | --- |
| iOS / Apple | `ios/AppleColorEmoji.ttf` | `samuelngs/apple-emoji-ttf`, `AppleColorEmoji-Linux.ttf` release asset |
| Google / Pixel | `google/NotoColorEmoji.ttf` | `googlefonts/noto-emoji` main branch |
| Blobmoji | `blobmoji/Blobmoji.ttf` | `C1710/blobmoji` latest release |
| Facebook | `facebook/Facebook-Emoji.ttf` | `infofintech/typography` main branch |

The Apple font assets and artwork remain the property of Apple Inc. Confirm
that a release containing third-party font binaries is permitted for the
intended distribution channel. The source repository URLs are documented in
the project README.
