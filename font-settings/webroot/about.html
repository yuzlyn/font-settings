Font Settings

A universal KernelSU module for managing system fonts and Emoji on Android 8.0 and later.

@yuzlyn

Compatibility

  • Android 8.0 or later (API 26+).
  • KernelSU or a compatible WebUI and systemless module implementation.
  • Standard Android familyset or fonts-modification XML font configuration.

Devices using a private font engine may be rejected during installation instead of receiving an unsafe configuration.

Features

  • Upload separate Chinese and Latin TTF files.
  • Use four built-in Emoji styles or upload a custom TTF/OTF.
  • Detect the device's actual font XML and Emoji target filenames during installation.
  • Adjust variable fonts across 100-900 weight, with the slider appearing for uploaded variable fonts.
  • WebUI languages: Simplified Chinese, Traditional Chinese for Taiwan, and English.

How it works

The installer backs up the device's font configuration, rewrites only the default Latin and Chinese locale families, and mounts the generated files through KernelSU. The system partition is never modified directly.

Built-in Emoji

  • iOS / Apple
  • Google / Pixel
  • Blobmoji
  • Facebook

Recovery

If fonts are missing or the system cannot start normally, disable the module through KernelSU and restart. With adb root available:

adb shell su -c 'touch /data/adb/modules/font-settings/disable'
adb reboot
